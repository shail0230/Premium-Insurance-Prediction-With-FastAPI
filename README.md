Patient Management System & Insurance Premium Predictor
A full-stack Python application built with FastAPI (backend) and Streamlit (frontend), featuring a Patient Management REST API and an ML-powered Insurance Premium Category Predictor.

Project Overview
This repository contains two integrated components:
Patient Management API — A complete CRUD REST API to manage patient records, calculate BMI, and provide health verdicts.
Insurance Premium Predictor — A machine learning model served via FastAPI with a Streamlit UI to predict insurance premium categories based on user inputs.

Tech Stack
Backend - FastAPI, Pydantic
Frontend - Streamlit
ML Model - Scikit-learn (pkl)
Data Store - JSON file
Language - Python 3.8+
